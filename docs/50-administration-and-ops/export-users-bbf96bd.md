# Export Users

To synchronize SAP BTP user data with other systems, you can export the data from a global account, subaccount, or directory to a CSV file.



<a name="loiobbf96bd825114aa89d011153ee03993c__prereq_export_users"/>

## Prerequisites

You have the relevant administrator authorizations for the account, from which you want to export users.



## Procedure

1.  Open the SAP BTP cockpit and navigate to your global account, subaccount, or directory.

2.  From the side navigation, select *Security* \> *Users*.

3.  Select <span class="SAP-icons-V5"></span> \(Export\).

4.  Choose *Export All Users* or *Export All Users with Role Collections*.

    The SAP BTP cockpit exports user data into a CSV file, which is downloaded to your browser's default download folder.

    The CSV file contains these columns:

    -   User Name

    -   Identity Provider

    -   Last Name

    -   First Name

    -   E-Mail

    -   Last Updated

    -   Last Login

    -   Assigned Role Collection \(only available if you choose *Export All Users with Role Collections*\)
